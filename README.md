# Afon Valley Hub

Internal mobile-first club hub for Afon Valley FC.

## Live app

https://isljjtspkqsyhkjmmhiq.supabase.co/functions/v1/avfc-hub

## Stack

- Supabase Auth for member logins
- Supabase Postgres for shared club data
- Row Level Security for role-based access
- Supabase Edge Function for the zero-cost hosted web app

## Current modules

- Player register
- Subs and payments
- Fines
- Kit washing tracker
- Training attendance
- Fixtures and match availability
- Restricted emergency details
- Role-based admin approvals

The first account created becomes the Chair account. Later accounts require Chair approval.
